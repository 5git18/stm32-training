# 电控组第一次培训

## 1. 环境配置

参考中科大RM电控合集之《手把手Keil+STM32CubeMX+VsCode环境配置》（[【中科大RM电控合集】手把手Keil+STM32CubeMX+VsCode环境配置](https://www.bilibili.com/video/BV1bU4y1D7nJ?vd_source=610f51e8c270c66144f249773bb7f63b)）

> **注：**
> 1）该视频中单片机选型为F401系列，我们培训用的是F103C8T6，故大家在配置时应注意选择对应的型号；
> 2）该视频最后安装git，我们改换安装github desktop，有关github desktop和git相关知识可参考以下链接：https://acn3ad0d3r22.feishu.cn/wiki/BdcfwZihKit3fJkNlY2cMJcWnqh

## 2. 学习内容

本次培训主要讲解GPIO相关知识，需要掌握GPIO的输入和输出功能，相关资料可参考中科大RM电控合集，keysking的stm32教程gpio部分；链接如下：

[【STM32入门教程-2025】第3集 绚丽小灯 点灯宗师 | keysking的stm32教程](https://www.bilibili.com/video/BV1Cd4y1L7kH?vd_source=610f51e8c270c66144f249773bb7f63b)

## 3. 作业

实现3个LED灯以1s为周期闪烁；按键长按时三个LED灯呈现流水灯效果，松开后恢复闪烁，完成时间为1周，提交内容包括工程代码和演示视频；

## 4. 物料清单

LED灯，按键，stm32f103c8t6，stlink，面包板，杜邦线
